# Ashish Portfolio (Clean & Modern)

A professional, responsive portfolio website for an App Developer.

## Features
- **Clean UI**: Black & White theme with a modern look.
- **Dark Mode**: Toggleable dark/light theme.
- **Responsive**: Fully functional on mobile, tablet, and desktop.
- **Sections**: Hero, About, Skills, Projects, Services, Contact.

## Tech Stack
- HTML5
- CSS3 (Variables, Flexbox, Grid)
- JavaScript (Vanilla)

## Setup
1. Clone the repository.
2. Open `index.html` in your browser.

## Customization
- Replace images in `assets/img/`.
- Update text content in `index.html`.
- Add your Resume PDF to `assets/resume.pdf`.
